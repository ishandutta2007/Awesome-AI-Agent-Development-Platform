### 📌 Overview & SEO Summary
Welcome to the ultimate curated directory of **AI agent development platforms**, **open-source multi-agent orchestration frameworks**, and **visual agent builders**. Whether you are looking for enterprise-grade commercial solutions (such as *Salesforce Agent Studio*, *Microsoft Copilot Studio*, and *Stack AI*), or self-hostable open-source alternatives (like *LangGraph*, *CrewAI*, and *Dify*), this list covers category leaders, multi-agent architectures, and privacy-respecting agent infrastructure.

**Key Market Context:**
- **LangGraph** has surpassed CrewAI in GitHub stars in early 2026, driven by **enterprise adoption** of its **state-graph model** for production agents with complex control flow, retries, checkpoints, and human-in-the-loop [citation:13].
- **CrewAI** offers the **fastest framework to prototype with** — **~20 lines to a working multi-agent demo** with role-based abstraction [citation:13], though at production scale it can consume **24× more tokens** than alternatives like OpenAI Agents SDK [citation:11].
- **Dify** is the **leading open-source visual builder** with **157K+ GitHub stars**, offering a **complete visual workflow builder, RAG pipelines, and model-agnostic support** [citation:3][citation:20].
- **AutoGen** pioneered **conversational multi-agent teams** with **61K+ GitHub stars**, though Microsoft has positioned **Microsoft Agent Framework** as its strategic successor for new projects [citation:8][citation:18].

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Dify](https://github.com/langgenius/dify)** [![Stars](https://img.shields.io/github/stars/langgenius/dify?style=social&color=white)](https://github.com/langgenius/dify/stargazers)  
  **LLMOps platform with agentic workflows**, Apache-2.0 licensed. **157K+ GitHub stars** — **the leading open-source visual agent builder** [citation:3]. **Visual drag-and-drop workflow builder**. **Built-in RAG pipelines and agent nodes**. **100+ LLM providers**. **Self-hosted or Dify Cloud**. **Prompt IDE, LLMOps, and Backend-as-a-Service** [citation:20]. 🎨

- **[LangGraph](https://github.com/langchain-ai/langgraph)** [![Stars](https://img.shields.io/github/stars/langchain-ai/langgraph?style=social&color=white)](https://github.com/langchain-ai/langgraph/stargazers)  
  **Stateful production agents with complex control flow**, MIT licensed. **The most mature general-purpose production agent framework** [citation:13]. **State graph model** with explicit nodes, edges, and persistent state [citation:7]. **Time-travel debugging** for replaying agent runs from checkpoints. **Best human-in-the-loop support** [citation:17]. **Steeper learning curve than CrewAI** [citation:13]. 🕸️

- **[MetaGPT](https://github.com/geekan/MetaGPT)** [![Stars](https://img.shields.io/github/stars/geekan/MetaGPT?style=social&color=white)](https://github.com/geekan/MetaGPT/stargazers)

- **[AutoGen](https://github.com/microsoft/autogen)** [![Stars](https://img.shields.io/github/stars/microsoft/autogen?style=social&color=white)](https://github.com/microsoft/autogen/stargazers)  
  **Conversational multi-agent systems**, CC-BY-4.0 licensed. **61K+ GitHub stars** — **Microsoft's multi-agent framework** [citation:8]. **AutoGen Studio for no-code multi-agent workflows**. **Excellent human-in-the-loop support** and **flexible communication patterns** [citation:2]. **Verbose communication increases token costs** [citation:2]. **Microsoft Agent Framework positioned as strategic successor** for new projects [citation:18]. 🏛️

- **[CrewAI](https://github.com/crewAIInc/crewAI)** [![Stars](https://img.shields.io/github/stars/crewAIInc/crewAI?style=social&color=white)](https://github.com/crewAIInc/crewAI/stargazers)  
  **Framework for orchestrating role-playing autonomous AI agents**, MIT licensed. **59K+ GitHub stars** — **the fastest framework to prototype with** [citation:13]. **Role-based DSL** with agents defined by role, goal, and backstory [citation:2]. **~20 lines to a working multi-agent demo**. **Free for self-hosted deployments**. **Can consume 24× more tokens than OpenAI Agents SDK at production scale** [citation:11]. 👥
